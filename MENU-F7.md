# Menu F7

Vào lobby rồi nhấn F7. Nếu game chưa mở được, giải quyết thông báo Steam trước.

| Tính năng | Vị trí |
| --- | --- |
| Đồ ăn / vật phẩm | Item Spawner → Search → Quantity → GIVE TO ME |
| Cho người đã chọn | Item Spawner → GIVE TO TARGET |
| Đến đồng đội | Player → Teleport → MYSELF TO TARGET |
| Đưa đồng đội tới mình | Player → Teleport → TARGET TO ME |
| Hồi sinh | Player → Health & Status → RESURRECT SELF / SELECTED |
| Thể lực / bất tử | Player → Health & Status → Infinite Stamina / Immortality |
| Thiết lập menu | Mod Config |

Nếu danh mục trống, vào màn chơi rồi Refresh. Nếu Item Spawner bị tắt, xem Mod Config → Built-in Quality of Life. Tên mục dựa trên mã nguồn, chưa kiểm chứng trong lobby với game hiện tại. Đọc nhãn quyền Host Only / Everyone Needs Mod / Unsupported. Chỉ dùng thao tác ảnh hưởng người khác trong phòng riêng đã thống nhất.

Bản Teck tương thích sửa lỗi userID, không bảo đảm mọi tính năng của bản Development hoạt động. F10 đổi Tiếng Việt / English. Xem LOCALIZATION-VI-EN.md.
